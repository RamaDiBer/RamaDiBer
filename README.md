## 👋 About me

I'm an **IT infrastructure and support technician** working in industrial and logistics environments. I currently run IT operations for a production site and I'm the site's **5S leader**. I'm studying for an **Associate Degree in Data Science and Artificial Intelligence (ISTEA)**.

Knowing the operation from the inside, I want data to drive decisions: I build **Power BI dashboards** on real operational data (Jira, production, continuous improvement) and use **Python** to clean, analyze and automate.

- 📊 **End-to-end BI:** extraction (Jira REST API, SharePoint, Excel), Power Query, star-schema modeling, DAX and report design.
- 📈 **Operational KPIs:** SLA, backlog, downtime, productivity, plan vs. actual and recurring failures.
- 🗣️ **Quarterly performance reviews** presented to several business areas.
- 🌱 **Currently learning:** statistics, machine learning and applied AI, plus more Python and SQL.
- 🌎 Spanish (native) · English B2 (EF SET) · French (basic)
